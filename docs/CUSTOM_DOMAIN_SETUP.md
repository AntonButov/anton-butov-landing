# 🌐 Настройка кастомного домена antonbutov.com

## 📋 Что уже сделано

✅ CNAME файл создан с доменом `antonbutov.com`  
✅ Файл будет автоматически развернут при следующем деплое  

## 🔧 Настройка DNS

### 1. **Настройка DNS записей у вашего провайдера домена**

Вам нужно добавить следующие DNS записи для домена `antonbutov.com`:

#### Вариант A: CNAME запись (рекомендуется)
```
Тип: CNAME
Имя: @ (или оставить пустым)
Значение: antonbutov.github.io
TTL: 3600 (или автоматически)
```

#### Вариант B: A записи (альтернативный способ)
```
Тип: A
Имя: @ (или оставить пустым)
Значение: 185.199.108.153
TTL: 3600

Тип: A
Имя: @ (или оставить пустым)
Значение: 185.199.109.153
TTL: 3600

Тип: A
Имя: @ (или оставить пустым)
Значение: 185.199.110.153
TTL: 3600

Тип: A
Имя: @ (или оставить пустым)
Значение: 185.199.111.153
TTL: 3600
```

### 2. **Настройка в GitHub Pages**

1. Перейдите в репозиторий: `https://github.com/AntonButov/anton-butov-landing`
2. Settings → Pages
3. В разделе "Custom domain" введите: `antonbutov.com`
4. Нажмите **Save**
5. ✅ Отметьте галочку "Enforce HTTPS" (если доступно)

## 🚀 Деплой изменений

После настройки DNS выполните деплой:

```bash
# Закоммитьте изменения
git add composeApp/src/wasmJsMain/resources/CNAME
git commit -m "Add custom domain antonbutov.com"
git push origin master
```

## ⏱️ Время ожидания

- **DNS изменения**: 24-48 часов для полного распространения
- **GitHub Pages**: 5-10 минут после деплоя
- **HTTPS сертификат**: до 24 часов (автоматически)

## 🔍 Проверка настройки

### 1. **Проверка DNS**
```bash
# Проверьте CNAME запись
dig antonbutov.com CNAME

# Или используйте онлайн инструменты:
# https://dnschecker.org
# https://whatsmydns.net
```

### 2. **Проверка GitHub Pages**
- Settings → Pages → Custom domain должен показывать `antonbutov.com`
- Статус должен быть "Your site is published at https://antonbutov.com"

### 3. **Проверка сайта**
- https://antonbutov.com (основной домен)
- https://antonbutov.github.io/anton-butov-landing/ (резервный URL)

## 🛠️ Устранение проблем

### DNS не обновился
- Подождите 24-48 часов
- Проверьте настройки у провайдера домена
- Убедитесь, что TTL не слишком высокий

### GitHub Pages показывает ошибку
- Проверьте, что CNAME файл развернут в gh-pages ветке
- Убедитесь, что домен введен правильно в настройках
- Проверьте логи деплоя в Actions

### HTTPS не работает
- Подождите до 24 часов для автоматического сертификата
- Убедитесь, что "Enforce HTTPS" включен в настройках

## 📞 Поддержка

Если возникли проблемы:
1. Проверьте логи в Actions → Deploy
2. Обратитесь к провайдеру домена для проверки DNS
3. Проверьте настройки в GitHub Pages
